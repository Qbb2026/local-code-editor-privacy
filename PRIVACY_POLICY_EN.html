Draftstead Privacy Policy

Effective date: August 12, 2026

Draftstead is published by Kalen. Questions can be sent to kalen010901@gmail.com.

Summary

Draftstead is an offline, local-first editor with no account, server, cloud sync, analytics, advertising, telemetry, or third-party API. Draft/file content is not uploaded, shared, or sold.

User-provided content

Text/code the user types, pastes, or explicitly opens is processed locally for editing, search/replace, highlighting, save/download, and recovery. Webpages, browsing history, cookies, and unchosen files are not accessed.

Crash-safe recovery

chrome.storage.local stores workspace names, open tab names/text, unsaved buffers, saved-text comparison copies, language, active tab, cursor/selection, scroll position, recent selected file names/open times, theme, and tab size. Recovery copies never automatically overwrite real files.

Local files

User-initiated File System Access APIs open/save selected files when available. Live handles remain only in memory for the current session. Standard local file input/download is the fallback; directories are not scanned.

Configuration

User-triggered configuration export contains only theme and tab size—not document text, workspace names, or recent file names. Import requires a selected JSON file.

Network and permissions

No application network requests occur. Content, file names, buffers, settings, diagnostics, and handles are not transmitted. The storage permission supports recovery/preferences. No host permissions or content scripts are used.

Collection, sale, analytics, and sharing

No publisher-side collection, sale, sharing, advertising, analytics, telemetry, crash reporting, tracking, or remote logging occurs.

Limited Use

Chrome API information and user-provided content are used only for offline editing and local recovery. They are not used for advertising, transferred to brokers, used to build profiles, or used for unrelated purposes. Human access does not occur because data is not transmitted.

Retention

Recovery data stays local until tabs/workspaces are deleted, storage is cleared, or the extension is uninstalled. User-saved files remain under user control.

Children

This developer/productivity tool is not directed to children under 13.

Changes

Material changes update this policy and listing before release.
